# Agenda de Contatos

Sistema simples de agenda de contatos em Python, com menu:

- Cadastrar um novo contato (nome, telefone e email)
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar
python agenda.py
